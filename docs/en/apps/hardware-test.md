# Hardware Test

Main menu key: `h`

A second-level entry for display, sensor, and peripheral tests. The shelf holds up to 8 entries per page — flip with `[` `]` or the arrow keys; number keys restart from `1` on each page. Some tools also have letter shortcuts that work **from any shelf page**. `ESC` / `GO` returns a child tool to the Hardware Test shelf; press it again on the shelf to return to the main menu.
