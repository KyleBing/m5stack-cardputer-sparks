# MATRIX

Entry: main menu `g` → Games page 2 `3`

Full-screen Matrix-style code rain with layered falling glyph columns and no title overlay. `-` / `=` set fall speed; `Space` / `GO` triggers a short burst.

## Shortcuts

| Key | Action |
|-----|--------|
| `-` `=` | Fall speed 1–5 |
| `Space` / `GO` | Pulse burst (brief column speedup) |
| `r` | Reshuffle columns |
| `h` | Help |
| `ESC` / `GO` | Back to the games shelf |
