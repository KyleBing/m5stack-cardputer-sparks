# WAVE

Entry: main menu `g` → Games page 2 `4`

Layered Bézier “silk” waves: several phase-offset curves stack into a soft ripple. `-` / `=` set speed, `c` cycles themes, `Space` / `GO` pulses amplitude.

## Shortcuts

| Key | Action |
|-----|--------|
| `-` `=` | Wave speed 1–5 |
| `c` | Cycle color theme |
| `Space` / `GO` | Amplitude pulse |
| `r` | Reset phase |
| `h` | Help |
| `ESC` / `GO` | Back to the games shelf |

## Notes

- No header / tip; full-screen draw.
- Works well as an ambient / screensaver-style demo.
