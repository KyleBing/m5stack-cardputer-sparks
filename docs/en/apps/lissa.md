# LISSA

Entry: main menu `g` → Games page 2 `6`

Full-screen Lissajous toy: the `a:b` frequency ratio morphs slowly while phase keeps rotating. `-` / `=` set speed, `c` cycles themes, `Space` / `GO` pulses phase.

## Shortcuts

| Key | Action |
|-----|--------|
| `-` `=` | Animation speed 1–5 |
| `c` | Cycle color theme |
| `Space` / `GO` | Phase pulse |
| `r` | Reset frequency params |
| `h` | Help |
| `ESC` / `GO` | Back to the games shelf |
