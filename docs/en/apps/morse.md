# Morse

Main menu key: `j`

Press a letter or number to play its Morse code tone. The active symbol is highlighted while a live waveform and per-symbol progress bar follow the sound.

## Shortcuts

| Key | Action |
|-----|--------|
| `a`–`z` / `0`–`9` | Play the matching Morse code |
| `-` | Lower frequency |
| `=` | Raise frequency |

## Usage

1. Press a letter or number; volume follows global `sound.volume`.
2. Use `-` / `=` to a comfortable pitch.
3. The green dot or dash is the active symbol; the waveform and progress bar show its duration.
4. Handy for practice or a simple beacon demo.
