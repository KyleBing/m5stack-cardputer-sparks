# PCLOCK

Entry: main menu `g` → Games page 2 `5`

Particles assemble into clock digits. They track time normally; `Space` / `GO` or `r` triggers a reshuffle morph. `m` toggles `HH:MM` vs `HH:MM:SS`.

## Shortcuts

| Key | Action |
|-----|--------|
| `Space` / `GO` / `r` | Reshuffle morph |
| `m` | Toggle `HH:MM` / `HH:MM:SS` |
| `h` | Help |
| `ESC` / `GO` | Back to the games shelf |

## Notes

- No header / tip; time comes from the device RTC.
- Separate from the main-menu Time app — does not write `time.*` config.
