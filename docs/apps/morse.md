# Morse 摩斯

主菜单按键：`j`

按字母或数字键播放对应摩斯电码音调，可调节音调频率。播放时会逐个高亮点划，并同步显示实时信号波形和单符号进度。

## 快捷键

| 按键 | 作用 |
|------|------|
| `a`–`z` / `0`–`9` | 播放对应摩斯码 |
| `-` | 频率降低 |
| `=` | 频率升高 |

## 使用说明

1. 进入后直接按字母或数字发声；音量受全局 `sound.volume` 影响。
2. 用 `-` / `=` 调到舒适音高。
3. 绿色点划表示当前正在发声的符号，下方波形和进度条显示持续时间。
4. 适合练习或简易信标演示。
