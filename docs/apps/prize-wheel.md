# Prize Wheel 抽奖轮

进入方式：主菜单 `g` → Games `3`

彩色扇区抽奖轮。长按空格蓄力旋转，或摇晃以中等力度开转；停下后顶部指针指向中奖格，金色结果牌显示 `#N`。

## 快捷键

| 按键 | 作用 |
|------|------|
| 长按 `Space` / `GO` | 蓄力，松开后旋转（1.8 秒满力） |
| 摇晃设备 | 以约 55% 力度旋转（上升沿触发一次） |
| `-` `=` | 项目数 − / +（2–12；转动中亦可，会重置） |
| `,` `.` | 同 `-` / `=` |
| `h` | Help |

## 说明

- 长按空格或侧边 `GO` 时，底部 `POWER` 条实时显示 0–100% 蓄力。
- 指针固定在十二点方向，轮盘在其下减速转动。
- 停稳后高亮中奖扇区，结果牌从上滑入并带扫光。
- 改格数会立即停转并回到初始姿态。
