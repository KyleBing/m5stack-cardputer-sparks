# Font 字体

进入方式：主菜单 `h` → Hardware Test `3`

无 Header、无底栏 tip。左上角 Font2 显示序号与名称；右上角红框标出单字占用，框内放一个示例字，框下 5px 显示宽×高。正文为数字与 pangram（`The quick brown fox jumps over the lazy dog`）。一屏放不下时用上下键滚动。

## 快捷键

| 按键 | 作用 |
|------|------|
| 左右箭头 · `,` `/` · `[` `]` | 上一 / 下一字体 |
| 上下箭头 · `;` `.` | 滚动样本 |
| `h` | Help |

## 使用说明

用于确认 UI 字体渲染与字号；Font6 / 7 / 8 仅预览数字。列表只含实测可用的内置字体。无编辑功能。
