# Neon FX 动画

进入方式：主菜单 `g` → Games `6`

高帧率霓虹动画演示。全屏 8-bit 调色板 Sprite：像素索引场只在切换形态或移动核心时生成，正常动画帧只轮转 256 色调色板并整块推送到屏幕。另含软渲染旋转立方体（`CUBE`）。

## 快捷键

| 按键 | 作用 |
|------|------|
| `e` `a` `s` `d` | 移动核心 / 立方体姿态 |
| `c` | 切换配色 |
| `m` 或 `,` `.` | 切换 Vortex / Plasma / Tunnel / Cube |
| `-` `=` | 降低 / 提高速度 |
| `r` | 反转流动 / 旋转方向 |
| `Space` / `GO` | 触发高亮脉冲 |
| `h` | Help（含实测 FPS） |

## 说明

- 无 header / tip，动画铺满 240×135；左上角叠实测 FPS。
- 全屏 Sprite 约占 32 KB，退出 App 时立即释放。
- `CUBE` 为自写透视投影 + 画家算法填面，无外部 3D 库。
- 按 `ESC` / `GO` 返回主菜单。
