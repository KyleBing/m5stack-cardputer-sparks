# Dice 骰子

主菜单按键：`z`

暖白实体骰子的桌面物理模拟。摇晃或空格投掷；IMU 晃动强度会直接控制骰子的运动幅度，停稳后缓动到面朝上姿态。

## 快捷键

| 按键 | 作用 |
|------|------|
| `-` `=` | 骰子数量 − / +（1–5） |
| `Space` | 投掷 |
| 摇晃设备 | 投掷（上升沿触发一次） |
| `h` | Help |

## 说明

- 骰子在覆盖整屏的绿色绒布桌面滚动、弹跳和互撞。
- 轻摇产生小幅扰动，猛摇会连续施加更强的平移、弹跳与旋转冲量。
- 最终姿态使用平滑缓动完成，不会突然跳变；停稳后以动态金色结果牌显示总点数。
- 骰面点数使用透视定位和加大圆点，保持滚动时的可读性。
