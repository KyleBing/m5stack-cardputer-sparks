# Snake 贪吃蛇

进入方式：主菜单 `g` → Games 第 2 页 `1`

40 × 20 格的经典贪吃蛇。蛇身从头到尾渐暗，方向一眼可辨；每吃 5 个普通果实会刷出一个限时的金色果实。撞墙模式与穿墙模式的最高分分开记录。

## 快捷键

| 按键 | 作用 |
|------|------|
| `;` `,` `.` `/` / 方向键 / `WASD` | 转向（也用于开局） |
| `Space` / `GO` | 暂停 / 继续；结束后重开一局 |
| `r` | 重开一局 |
| `m` | 切换 WALL（撞墙死）/ WRAP（穿墙）（会重开一局） |
| `-` `=` | 速度档位 1–5 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 玩法要点

- **计分**：普通果实 +1，金色果实 +5。金色果实存在 7 秒，剩余不足 2 秒时开始闪烁。
- **加速**：每吃一个普通果实，步进间隔缩短 3ms，最快到 55ms；`-` / `=` 调的是起始档位。
- **转向缓存**：一步之内连按两次方向会排队执行，快速拐直角不会被吞键；禁止 180° 掉头。
- **顶栏**：`S` 分数、`L` 蛇长、`B` 当前模式最高分，右侧显示模式与速度档。

## 记录

最高分按模式分别保存在 Flash 的 `/snake_rec.dat`：WALL 与 WRAP 各一份，开局画面同时显示最高分和总场次。
