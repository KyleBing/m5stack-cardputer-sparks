# Snake 贪吃蛇

进入方式：主菜单 `g` → Games 第 2 页 `1`

40 × 20 格的经典贪吃蛇。蛇身从头到尾渐暗，方向一眼可辨；每吃 5 个普通果实会刷出一个限时的金色果实。撞墙模式与穿墙模式的最高分分开记录。

## 快捷键

| 按键 | 作用 |
|------|------|
| `;` `,` `.` `/` / 方向键 / `EASD` | 转向（也用于开局） |
| `Space` / `GO` | 暂停 / 继续；结束后重开一局 |
| `r` | 重开一局 |
| `m` | 切换 WALL（撞墙死）/ WRAP（穿墙）（会重开一局） |
| `i` | 开关 IMU 倾斜转向（同时重新校准中立姿态） |
| `-` `=` | 速度档位 1–5 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 玩法要点

- **计分**：普通果实 +1，金色果实 +5。金色果实存在 7 秒，剩余不足 2 秒时开始闪烁。
- **加速**：每吃一个普通果实，步进间隔缩短 3ms，最快到 55ms；`-` / `=` 调的是起始档位。
- **转向缓存**：一步之内连按两次方向会排队执行，快速拐直角不会被吞键；禁止 180° 掉头。
- **顶栏**：`S` 分数、`L` 蛇长、`B` 当前模式最高分，右侧显示模式与速度档；IMU 介入时在最高分右侧亮起金色 `IMU` 徽章，没有板载 IMU 时按 `i` 会短暂显示红色 `NO IMU`。

## IMU 倾斜转向

按 `i` 开启后，倾斜机身即可转向，键盘方向键仍然可用，两者可以混着操作。

- **中立姿态**：按 `i` 的瞬间会把当前握持姿势记为“不动”的基准，所以不需要把机器端平；坐姿变了再按两次 `i` 重新校准即可。
- **四个方向量程对称**：判定用的是「当前重力方向相对校准姿态转过的角度」，而不是某个轴的原始读数。所以哪怕端得很斜，继续朝同一侧倾也不会顶到 ±1g 的量程尽头，上下左右都能触发。
- **方向对应**：往上倾就往上走，往右倾就往右走，和屏幕方向一致；屏幕右方由「屏幕上方 × 校准时的重力方向」推出，不写死机身轴向。
- **灵敏度**：转过约 9° 就转向，回落到约 4.5° 以内才算回中（迟滞），并且要求倾斜方向偏向某一个轴，避免斜着端着时上下左右乱跳。
- **触发时机**：只在倾斜方向发生变化时转向一次，保持倾斜不会反复触发；待开局时倾斜也会直接开局。
- **倾斜指示点**：`IMU` 徽章右侧的小方框里有个点，跟着倾斜方向偏移，可以直接确认四个方向都被识别到。
