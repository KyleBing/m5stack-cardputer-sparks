# PCLOCK 粒子时钟

进入方式：主菜单 `g` → Games 第 2 页 `5`

粒子聚合成时钟字形：平时随时间走字，`Space` / `GO` 或 `r` 触发重排变形。`m` 在 `HH:MM` 与 `HH:MM:SS` 之间切换。

## 快捷键

| 按键 | 作用 |
|------|------|
| `Space` / `GO` / `r` | 重排粒子（morph） |
| `m` | 切换 `HH:MM` / `HH:MM:SS` |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 说明

- 无 header / tip；时间来自设备 RTC。
- 与主菜单 Time App 独立，不写入 `time.*` 配置。
