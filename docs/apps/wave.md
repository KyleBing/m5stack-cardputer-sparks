# WAVE 丝波

进入方式：主菜单 `g` → Games 第 2 页 `4`

多层贝塞尔「丝波」动画：多条相位错开的曲线叠成柔和波动。`-` / `=` 调速，`c` 换配色，`Space` / `GO` 幅度脉冲。

## 快捷键

| 按键 | 作用 |
|------|------|
| `-` `=` | 波动速度 1–5 |
| `c` | 切换配色主题 |
| `Space` / `GO` | 幅度脉冲 |
| `r` | 重置相位 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 说明

- 无 header / tip，全屏绘制。
- 适合当桌面氛围灯 / 屏保式演示。
