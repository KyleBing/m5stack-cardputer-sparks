# Newton Cradle 牛顿摆

进入方式：主菜单 `g` → Games `5`

五球牛顿摆物理模拟。钢球受重力沿吊索摆动，通过约束冲量碰撞传递动量，并带有轻微空气阻尼与接近弹性碰撞的能量损耗。

## 快捷键

| 按键 | 作用 |
|------|------|
| `1` / `2` / `3` | 从左侧释放对应数量的钢球 |
| `Space` / `GO` | 重放当前数量 |
| `r` | 重置为单球释放 |

## 模拟与画面

- 使用固定长度摆约束、重力角加速度和按时间计算的空气阻尼。
- 球间碰撞按约束方向的有效质量求解，多轮顺逆序冲量使动量在同一帧穿过球列。
- 抛光钢球采用逐像素球面法线光照，包含环境暗带和镜面高光。
- 金属支架、双吊索、胡桃木底座以及随高度变化的工作台阴影共同组成场景。
