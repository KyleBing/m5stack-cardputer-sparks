# LISSA 利萨茹

进入方式：主菜单 `g` → Games 第 2 页 `6`

全屏利萨茹（Lissajous）曲线玩具：`a:b` 频率比缓慢形变，相位持续旋转。`-` / `=` 调速，`c` 换配色，`Space` / `GO` 相位脉冲。

## 快捷键

| 按键 | 作用 |
|------|------|
| `-` `=` | 动画速度 1–5 |
| `c` | 切换配色主题 |
| `Space` / `GO` | 相位脉冲 |
| `r` | 重置频率参数 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 说明

- 无 header / tip。
- 与 [Curves](./curves) 里编号曲线中的 `LISSA` 方程不同：本项是独立的全屏动画 App。
