# Hardware Test 硬件测试

主菜单按键：`h`

硬件显示、传感器与外设测试的二层入口。子应用中按 `ESC` / `GO` 返回 Hardware Test 顶层，在顶层再次按下返回主菜单。

| 按键 | 子应用 | 说明 |
|------|--------|------|
| `1` | Display | 色块、棋盘格和像素线测试 |
| `2` | IMU | BMI270 加速度与姿态可视化 |
| `3` | Font | 字体预览 |
| `4` | Icons | 固件图标浏览 |
| `5` | RGB LED | 板载 LED 开关、颜色与亮度 |
| `6` | BLE | 扫描附近 BLE 设备 |
| `7` | InI2 | 内部 I2C 总线扫描 |
| `8` | ExI2 | 外部 I2C 总线扫描 |
