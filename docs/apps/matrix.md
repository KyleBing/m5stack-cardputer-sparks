# MATRIX 代码雨

进入方式：主菜单 `g` → Games 第 2 页 `3`

全屏 Matrix 风格代码雨：多层下落字符列，无标题叠字。`-` / `=` 调节下落速度；`Space` / `GO` 触发短暂爆发加速。

## 快捷键

| 按键 | 作用 |
|------|------|
| `-` `=` | 下落速度 1–5 |
| `Space` / `GO` | 脉冲爆发（列短暂加速） |
| `r` | 重排各列 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 说明

- 无 header / tip，动画铺满屏幕。
- 与 Curves 里的方程名 `LISSA` 无关；本页是独立视觉效果。
