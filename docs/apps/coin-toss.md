# Coin Toss 硬币

进入方式：主菜单 `g` → Games `1`

抛硬币物理动画。按空格或摇晃设备抛起；空中翻转并带落地弹跳，停稳后缓动到正面 / 反面，金色结果牌显示 `HEADS` / `TAILS`。

## 快捷键

| 按键 | 作用 |
|------|------|
| `Space` / `GO` | 抛掷（飞行中不可再次触发） |
| 摇晃设备 | 抛掷（IMU 上升沿触发一次） |
| `h` | Help |

## 说明

- 正视为正圆；翻转时只压缩水平方向，模拟透视。
- 正面为侧脸剪影，反面为放射徽记；高度越高阴影越小越淡。
- 结果在抛起时已随机确定，落地后缓动对齐到对应朝向。
- 顶栏 `IMU` / `KEY` 表示当前可用输入源（有 BMI270 时可摇晃）。
