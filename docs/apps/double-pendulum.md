# Double Pendulum 双摆混沌

进入方式：主菜单 `g` → Games `2`

耦合双摆混沌演示。末端质量更轻、第二段更长，轨迹更易发散；末端路径以渐变色残影绘制。

## 快捷键

| 按键 | 作用 |
|------|------|
| `Space` / `GO` | 重置为默认初始姿态 |
| `r` | 随机初始角度并清空轨迹 |
| `-=` | 调节第二段臂长（顶栏显示 `L2`） |
| `h` | Help |

## 说明

- 使用经典双摆角加速度方程，半隐式积分，带轻微阻尼防止异常帧能量爆炸。
- 每帧多分步积分，末端轨迹环形缓存约 72 点。
- 近端球较大、末端球较小，对应质量比；顶栏固定显示 `CHAOS`。
