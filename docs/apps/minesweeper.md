# Minesweeper 扫雷

进入方式：主菜单 `g` → Games `8`

完整规则的扫雷，三个难度各自记录最快通关时间与连胜。首次挖开的格子及其 8 个邻格保证无雷，所以开局一定能展开一片空地，不存在第一下就踩雷的运气局。

## 快捷键

| 按键 | 作用 |
|------|------|
| `;` `,` `.` `/` / 方向键 / `WASD` | 移动光标（按住可连发） |
| `Space` / `Enter` / `GO` | 挖开；光标在已翻开的数字上时执行和弦展开 |
| `f` | 插旗 / 取消插旗 |
| `1` `2` `3` | 切换 EASY / NORMAL / HARD（会重开一局） |
| `r` | 重开一局 |
| `b` | 打开 / 关闭记录页 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 难度

| 难度 | 棋盘 | 雷数 | 雷密度 |
|------|------|------|--------|
| EASY | 10 × 7 | 10 | 14.3% |
| NORMAL | 15 × 9 | 22 | 16.3% |
| HARD | 22 × 11 | 50 | 20.7% |

## 玩法要点

- **首挖保护**：雷在第一次挖开之后才布置，首格及其邻格必定安全，因此开局必然展开一片区域。
- **连锁展开**：挖到数字 0 的格子会沿邻格自动展开到数字边界，已插旗的格子不会被自动翻开。
- **和弦展开**：光标停在已翻开的数字上，若周围旗数与数字相同，按 `Space` 一次性翻开其余邻格——这是提速的关键操作，插错旗也会因此直接踩雷。
- **计时**：从第一次挖开开始计时，通关或踩雷时停表，最长显示 999 秒。
- **踩雷**：踩中的雷格标红，其余雷全部摊开，插错的旗会画上红叉。
- **通关**：剩余的雷自动插旗，弹出金色结果牌；破纪录时显示 `NEW BEST!`。

## 记录

按 `b` 打开记录页，按难度分别显示：

| 列 | 含义 |
|----|------|
| BEST | 最快通关秒数，未通关过显示 `--` |
| WIN/PLAY | 通关场次 / 总场次 |
| STREAK | 历史最长连胜 |

底部另外显示当前难度的**当前连胜**（踩雷即清零）。

记录保存在 Flash 的 `/mines_rec.dat`，重启和刷新固件都不会丢失（重新烧录文件系统才会清空）。
