# Minesweeper 扫雷

进入方式：主菜单 `g` → Games `8`

完整规则的扫雷，三个难度各自记录最快通关时间与连胜。首次挖开的格子及其 8 个邻格保证无雷，所以开局一定能展开一片空地，不存在第一下就踩雷的运气局。

## 快捷键

| 按键 | 作用 |
|------|------|
| `;` `,` `.` `/` / 方向键 / `EASD` | 移动光标（按住可连发） |
| `Space` / `]` / `Enter` / `GO` | 挖开；光标在已翻开的数字上时执行和弦展开 |
| `f` / `[` | 插旗 / 取消插旗 |
| `i` | 开关 IMU 倾斜移动光标（同时重新校准中立姿态） |
| `1` `2` `3` | 切换 EASY / NORMAL / HARD（会重开一局） |
| `r` | 重开一局 |
| `b` | 打开 / 关闭记录页 |
| `h` | Help |
| `ESC` / `GO` | 返回游戏选择页 |

## 难度

| 难度 | 棋盘 | 雷数 | 雷密度 |
|------|------|------|--------|
| EASY | 10 × 7 | 10 | 14.3% |
| NORMAL | 15 × 9 | 22 | 16.3% |
| HARD | 22 × 11 | 50 | 20.7% |

## 玩法要点

- **首挖保护**：雷在第一次挖开之后才布置，首格及其邻格必定安全，因此开局必然展开一片区域。
- **连锁展开**：挖到数字 0 的格子会沿邻格自动展开到数字边界，已插旗的格子不会被自动翻开。
- **插旗 / 排雷双键**：`[` 插旗、`]` 排雷，两键相邻，一只手就能来回切换，不用在 `f` 和 `Space` 之间跨手；原来的 `f` / `Space` 仍然可用。
- **和弦展开**：光标停在已翻开的数字上，若周围旗数与数字相同，按 `Space` / `]` 一次性翻开其余邻格——这是提速的关键操作，插错旗也会因此直接踩雷。
- **计时**：从第一次挖开开始计时，通关或踩雷时停表，最长显示 999 秒。
- **踩雷**：踩中的雷格标红，其余雷全部摊开，插错的旗会画上红叉。
- **通关**：剩余的雷自动插旗，弹出金色结果牌；破纪录时显示 `NEW BEST!`。

## IMU 倾斜移动光标

按 `i` 开启后，倾斜机身即可上下左右移动光标，键盘方向键仍然可用。开启时顶栏剩余雷数右侧会亮起金色 `IMU` 徽章；没有板载 IMU 时按 `i` 会短暂显示红色 `NO IMU`。

- **中立姿态**：按 `i` 的瞬间把当前握持姿势记为基准，不需要端平机器；姿势变了按两次 `i` 重新校准。
- **四个方向量程对称**：判定用的是「当前重力方向相对校准姿态转过的角度」，不是某个轴的原始读数，所以端得再斜也不会有哪个方向顶到量程尽头。
- **方向对应**：往上倾光标就往上走，往右倾就往右走，和屏幕方向一致；屏幕右方由「屏幕上方 × 校准时的重力方向」推出，不写死机身轴向。
- **像鼠标一样连走**：转过约 7° 就走一格，只要保持倾斜就一直走，回落到约 3.5° 以内才算回中；倾得越多走得越快，从 260ms 一格连续加速到约 22°（含）以上的 45ms 一格。
- **倾斜指示点**：`IMU` 徽章右侧的小方框里有个点，跟着倾斜方向偏移，可以确认四个方向都被识别到。
- **挖开 / 插旗**：仍然用 `Space` / `]` / `Enter` / `GO` 和 `f` / `[`，倾斜只负责移动光标。

## 记录

按 `b` 打开记录页，按难度分别显示：

| 列 | 含义 |
|----|------|
| BEST | 最快通关秒数，未通关过显示 `--` |
| WIN/PLAY | 通关场次 / 总场次 |
| STREAK | 历史最长连胜 |

底部另外显示当前难度的**当前连胜**（踩雷即清零）。

记录保存在 Flash 的 `/mines_rec.dat`，重启和刷新固件都不会丢失（重新烧录文件系统才会清空）。
